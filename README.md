# Фотобудка кофейни

Веб-приложение для планшета в кофейне: гость фотографируется на фронтальную камеру, снимок печатается на мини-термопринтере по Bluetooth.

Адрес: https://abdullamag.github.io/photo-booth/

- `index.html`: всё приложение (настройки кофейни в блоке `CONFIG`)
- `sw.js`: работа без интернета; при каждом релизе меняется `CACHE`
- `manifest.webmanifest` и иконки: установка на планшет как приложение

Настройки принтера: на главном экране удерживать плюшевый фотоаппарат 3 секунды.
Работает в Chrome на Android (камера и Web Bluetooth требуют HTTPS).
